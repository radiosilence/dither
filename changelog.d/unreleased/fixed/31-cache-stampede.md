- **A widely shared image costs the bucket one read.** Requests for an image not in memory wait for the first to fetch it, where each fetched it before: 200 at once for a new thumbnail made 199 reads of the bucket. The disk cache no longer reserves twice the largest upload above `MIN_FREE_BYTES`, which on a small disk left it next to nothing; an upload short of room already takes it back from the cache. Range requests that miss now count in `dither_cache_misses_total`.
