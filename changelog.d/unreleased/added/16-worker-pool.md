- **Workers form a pool.** Any number of workers, on any machine that reaches the web process's worker API, pull from one queue, so processing runs wherever there is room. A worker asks for a job and is held until one waits, fetches the upload, reports progress, sends back what it made and says how the job ended. The API listens on its own port (`WORKER_ADDR`), and anywhere but loopback requires `WORKER_TOKEN`.
